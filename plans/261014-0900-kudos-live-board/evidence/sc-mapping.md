## Summary

- PASS: SC-001 (incl. `/sun-kudos/<id>` guest guard), SC-002 (incl. neighbour fade), SC-003, SC-004 (exact VN time, clamp box heights), SC-005, SC-006 (split E2E and pgTAP), SC-007, SC-009, SC-010.
- PARTIAL with recorded reasons: SC-008 (100-node cap: real in SQL, no test reaches it; loading state: no spotlight loading UI to assert), SC-011 (one-card carousel at 375 and ≥1024 layout asserted only visually).
- No SC has a failing test. The PARTIAL rows are real coverage gaps, not app defects found by these tests. One app-side note: the 100-node cap lives only in the SQL RPC, so it has no test at any layer.
- Visual: 1440 is not within tolerance. See `visual/visual-mismatch-list.md`.
- Acceptance round (2026-10-14): K 60/60 exit 0, tsc 0, lint 0. Mutation probe: clamp removal fails the box check (384 vs 160 px). The fade mutation probe was inconclusive (single read during a 300 ms opacity transition); the spec uses `expect.poll`, which would time out on a permanently opaque neighbour, but this is reasoning, not a recorded failing run.
